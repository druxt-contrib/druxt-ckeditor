'@druxt-contrib/ckeditor': minor
---

Add the `DruxtCkeditor` component and the `$druxtCkeditor` plugin, which mount Drupal's own CKEditor 5 build in a Druxt frontend: the toolbar Drupal configured for the text format, image uploads over JSON:API, and a `copy` option that serves the editor's scripts from the site's own origin for a static build.
